## المصدر

تعتمد ملفات التشغيل على مستودع `raw13g/raw13g.github.io` عند المراجعة:

`401f6cc0c27d5ec69f56e7aa740158cd4189c41d`

التعديلات الخاصة بـGameYard محصورة في الواجهة، رسائل الحالة، الصور، وملف التخزين. لم تُعدّل ملفات الاستغلال أو الـoffsets أو الـpayload أو ملفات التصحيح الثنائية.

بعد أول زيارة ناجحة، انتظر حتى تظهر رسالة اكتمال حفظ الملفات، ثم اضغط زر التشغيل. احتفظ بذكر المصدر الأصلي عند إعادة النشر.
